# `rune-parts`

Catalog, parser, validator, HTML exporter, and optional Rune element renderer (`features = ["view"]`) for ```` ```ui ```` generative UI outlines.

Without the `view` feature, `rune-parts` is pure Rust with zero dependencies so CLIs, Workers, and Wasm builds can parse and check outlines without linking Rune. See [`../../skills/rune-ui/SKILL.md`](../../skills/rune-ui/SKILL.md) for the outline syntax and part catalog.
